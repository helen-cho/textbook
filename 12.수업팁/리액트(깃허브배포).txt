*****깃허브에 리액트 배포

1) gh-pages 패키지 설치
npm install gh-pages
yarn add gh-pages

2) package.json 수정
"scripts": {
    (...)
    "predeploy": "npm run build",
    "deploy": "gh-pages -d build"
  },

"homepage": "https://bam-j.github.io/pages/"

3) 빌드와 배포
git add .
git commit -m "메시지..."
git push origin master

npm run deploy


******리액트 배포
1) 프로젝트 빌드
npm run build

2) 서버실행
npx serve -s build
